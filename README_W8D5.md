\- AI Tutor integration

\- AI Quiz Generation

\- AI Learning Recommendations

\- Performance audit documentation



\## Tech Stack



\- Moodle

\- PHP

\- MariaDB

\- Docker

\- Git/GitHub

Moodle was configured using Moodle Docker.
